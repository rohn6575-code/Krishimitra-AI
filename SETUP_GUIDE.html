1
Install Prerequisites
Software you must install before anything else

Install all four of these on your laptop. Click the links to download:

A
Node.js — Download from https://nodejs.org → Choose the LTS version (green button). After install, verify:
CMD / Terminal
node --version
npm --version
✅ Should show: v18.x.x or higher and 9.x.x or higher
B
Python 3.10+ — Download from https://python.org/downloads → ⚠️ During install, check "Add Python to PATH"
Verify
python --version
pip --version
C
MongoDB Community — Download from https://mongodb.com/try/download/community → Install with default settings. MongoDB will run on port 27017 automatically.
D
VS Code Extensions — Open VS Code → Extensions panel (Ctrl+Shift+X) → Install:
• Live Server (by Ritwick Dey) — for frontend
• Python (by Microsoft) — for ML service
• Thunder Client (optional, for API testing)
⚠️ Do NOT proceed to next steps until Node, Python, and MongoDB are all installed.

3
Add Your Anthropic API Key
This is required — the AI features won't work without it
1
Go to https://console.anthropic.com → Sign up or login → Click API Keys → Create Key → Copy it
2
In VS Code, open the file server/.env and replace the placeholder:
server/.env — Edit this file
PORT=5000
NODE_ENV=development
MONGO_URI=mongodb://localhost:27017/krishimitra
JWT_SECRET=krishimitra_secret_key_2024
ANTHROPIC_API_KEY=sk-ant-PASTE_YOUR_KEY_HERE
ML_SERVICE_URL=http://localhost:5001
FRONTEND_URL=http://127.0.0.1:5500
⚠️ Never share your .env file or upload it to GitHub. The key looks like: sk-ant-api03-xxxxx...
✅ Save the file (Ctrl+S) after pasting your key.
4
Terminal 1 — Start Node.js Backend
Runs on http://localhost:5000

In VS Code, open Terminal 1. Run these commands one by one:

Terminal 1 — Node Server
Run these one by one
# Step 1: Go into server folder
cd server

# Step 2: Install all Node packages (takes 1-2 min, do once only)
npm install

# Step 3: Start the server
node server.js
✅ You should see:
🚀 KrishiMitra AI server running at http://localhost:5000
✅ MongoDB connected
❌ If MongoDB error: Make sure MongoDB is installed and running. On Windows search "Services" → find MongoDB → Start it.
💡 For development use npm install -g nodemon then nodemon server.js — it auto-restarts when you save files.
5
Terminal 2 — Start Python ML Service
Runs on http://localhost:5001 — needed for SHAP feature

Open a new terminal in VS Code (click + icon in terminal panel). Run these commands:

Terminal 2 — Python ML Service
Run these one by one
# Step 1: Go to ml-service folder
cd ml-service

# Step 2: Install Python packages (takes 2-3 min, do once only)
pip install -r requirements.txt

# Step 3: Train the ML models (do once only, creates model .pkl files)
python train_models.py

# Step 4: Start the Flask server
python app.py
✅ You should see:
🐍 KrishiMitra ML Service starting on http://localhost:5001
📊 SHAP Explainability: ENABLED
❌ If pip not found on Windows: use python -m pip install -r requirements.txt
💡 The Income, Advisory, Chat and Disease features work WITHOUT Python. Python is only needed for the SHAP "Explain AI" tab.
6

Common Errors & Fixes
Solutions to the most frequent problems

❌ "Cannot find module 'express'"

cd server
npm install

❌ "MongoDB connection refused"

# Windows: Open Services → find MongoDB → Start
# OR run in terminal:
net start MongoDB

❌ CORS error in browser console

Make sure you're opening index.html with Live Server (port 5500), not by double-clicking the file (file:// URL). The CORS is set to allow 127.0.0.1:5500 only.

❌ "Invalid API key" from income/advisory/chat

Your ANTHROPIC_API_KEY in server/.env is wrong. Go to console.anthropic.com, create a new key, and paste it. Make sure there are no spaces.

❌ SHAP feature says "ML service error"

# Make sure Python service is running:
cd ml-service
python app.py
# Visit: http://localhost:5001/health to confirm

❌ pip install fails on Windows

python -m pip install -r requirements.txt
